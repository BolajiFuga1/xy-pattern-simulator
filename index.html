Reference: Z1–Z16 and the rules

Rules used

  • Step 1: draw a number 1–26 and plot it as a line across columns 1–26. Repeat (up to max draws) until the same line appears twice in a row, then print the two lines. If that never happens, print NONE and stop everything.
  • Step 2: pick 4 different patterns from Z1–Z16 at random as C1–C4, shown as C4 C3 C2 C1.
  • C5–C8: read across rows. Row 1 of C1, C2, C3, C4 becomes C5; row 2 becomes C6; row 3 becomes C7; row 4 becomes C8 (this matches the example).
  • Addition (row by row): Y+Y=Y, Y+X=X, X+X=Y.
  • C9=C1+C2, C10=C3+C4, C11=C5+C6, C12=C7+C8, C13=C9+C10, C14=C11+C12, C15=C13+C14, C16=C15+C1.
  • If C15 is Z1, Z7 or Z11, pick 4 new patterns and rebuild.
  • C17=C1+C4+C7+C8, C20=C3+C7+C11+C15. If C20 isn't Z1, Z3, Z5, Z6, Z8, Z10, Z13 or Z15, C20 = Nil.
  • If 8 or more of C1–C16 equal C17, print them in a table and stop. Otherwise print None and do the next run.
